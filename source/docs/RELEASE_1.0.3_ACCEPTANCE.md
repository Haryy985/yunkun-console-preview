## 跳过与未覆盖项

- 10 项自更新替换、回滚或解包测试依赖 Unix shell 假程序或 Unix 文件名，在 Windows 跳过。本包不提供运行中自动替换二进制，升级采用备份迁移。
- 5 项符号链接测试因本机创建链接权限不足而跳过；不能把它们计为通过。
- 1 项真实模型上下文检查需要单独配置模型，未执行。
- 没有消耗客户第三方平台额度，没有用真实授权目标跑完整攻击任务；真实模型、供应商兼容、目标网络及代理质量仍须在部署环境验收。
- 没有将全部 Python 脚本移植为 Go。主动爬虫尚未作为新工具开放，需先接通受管出口与抓包。专项文档属于参考资料，不是新增运行能力。
- 独立报告交付角色、跨任务完整因果图和操作系统级网络隔离不在本次完成范围内。公网部署仍需单独的环境与权限验收。

## 交付核对

交付采用白名单组装，不复制运行中的安装目录。包内包含已编译程序、
PostgreSQL 运行时、官方 VC++ x64 离线安装器、内嵌页面、公开 Skills、许可证、升级说明及本记录。
不含开发者本地配置、数据库、登录密钥、代理密钥、会话、任务、日志或平台账号。

`SOURCE_MANIFEST.csv` 记录构建相关源码哈希，不包含源码正文；
`PACKAGE_MANIFEST.csv` 记录交付文件大小与 SHA-256（清单不记录自身）。
ZIP 外的 `SHA256SUMS.txt` 用于校验最终压缩包；验收时一并核对。

测试源码保留在开发目录的 `tests` 及各 Go 包中；客户包不携带测试数据库、
测试日志或开发者机器路径。完整变化及部署边界见 `RELEASE_1.0.3.md`。
