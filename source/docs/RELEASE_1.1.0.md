# 云鲲 v1.1.0 离线版：1.0.6 至 1.1.0

本版基于 1.0.6 的源码与完整离线运行时制作。安装、首次设置与数据迁移方式见
`OFFLINE_UPDATE.md`。升级时使用新目录和独立备份目录，绝不要把新文件直接覆盖
旧安装或把旧安装的私有数据重新打进公开包。

## 修复

1. 自定义 command 工具参数仅在原始模板上替换一次，避免参数中包含其他
   `{name}` 时经二次展开绕过 shell 引号。HTTP 模板继续保留原文替换语义。
2. 普通角色不再读取跨任务的任务、发现与流量证据，也不再看到代理池配置。
3. operator 不再能创建/控制任务并借 Agent 的宿主机 Bash 执行工具。管理员
   保留原功能。**兼容性变化**：operator/viewer 暂只可查询自身身份和健康接口。
   数据并未删除；重新开放需要任务所有权及隔离执行环境。
4. 登录按连接 IP 与账号在十分钟内分别限制 30 / 8 次尝试，并在数据库查询和
   bcrypt 之前拒绝超额请求，返回 HTTP 429 与 Retry-After。进程重启会清空
   内存限流状态，反向代理的共享 IP 会共享配额；公网还应增加边界访问控制。
5. Markdown 任务报告的资产汇总改为按任务 ID 计数，排除其他任务资产，也不再
   受原先单类型 100000 条分页上限影响；数据库读取失败时拒绝生成错误报告。

## 同步纳入的开发树改动

- 新增 Windows x64 标准离线安装的一键更新：管理员确认后自动下载与校验、
  停服、备份数据库和密钥、安装并重启；启动检查失败自动恢复程序及数据库快照。
  页面显示进度、结果和备份位置。运行中任务须先暂停；1.0.6 客户端首次需手动升级。
- 统一发布附件与更新检查使用的文件名，并兼容旧候选包名及两种校验清单名称。

- 代理池发现增加批次记录、原子游标、验证尝试和失败阶段；节点支持分页、筛选，
  区分出口 IP 证明和网站连通性，避免把连通性当作已取得出口 IP。FOFA/Quake
  节点在任务选路时检查验证新鲜度与最近失败状态，过期则停止受管出口选路。
- 批量验证改为有界工作队列；来源和节点页展示分层结果。空授权范围可以保存
  查询，但主动验证仍需满足授权检查。现有代理数据和凭据随升级脚本迁移。
- 模型请求用量记录标出供应商未返回用量的情况，界面显示缩写及精确数字；
  未知用量不假装为零，也不能把本地计数等同于供应商账单。
- 已验证漏洞的通知事件、投递状态与企微摘要排版调整；数据库迁移与相关
  回归用例随包内二进制一同提供。

## 未改变及部署边界

- 不修改 Agent 的规划、模型选择与管理员执行底座。
- `/api/auth/init` 是首次设置接口，部署到公网前应在本机完成初始化，并在网关
  层限制此接口；仅靠上述登录限流不能代替 TLS、访问控制和运行环境隔离。
- 这五项的回归验证不等于全代码安全审计，也不保证可直接安全地裸露公网。
- 代理池 V2 尚缺客户机与同条件工具的逐条对照、真实出口与抓包关联，以及
  旧业务库副本升级演练；未实现全部 Agent 网络工具的强制代理覆盖。
- 完整离线包不含作者的数据库、任务、日志、账号、JWT 密钥及代理凭据。
