# 云鲲 v1.1.3 离线版

相对 `v1.1.2-offline`，本版整理了漏洞登记和报告复现材料，并增加全新 Alibaba Cloud Linux 3 VPS 的单脚本安装。旧版 Release 保留，已有 1.1.2 客户可识别更高版本。

## 变化

- 漏洞登记恢复原版工具契约和字段处理，移除新增的质量门禁、审核界面与数据库写入；旧质量数据保留，不因升级删除历史表。
- 漏洞列表增加跨页批量删除。管理员接口先核对整批 ID 与权限，再在事务中删除；删除不可撤销，操作前应备份。
- HTTP 漏洞报告仅使用实际捕获的原始请求包（Burp 可导入的请求格式）。旧报告导出不再展示无法直接复现的 curl 命令；没有真实请求记录时保留证据不足提示，不合成请求包。
- 全新 Alibaba Cloud Linux 3 x86_64/aarch64 可下载对应架构的 `vpsinstall` 部署套件 ZIP，解压后在 root shell 执行 `bash install-vps.sh`。套件包含同平台完整离线 ZIP 和 SHA256SUMS。脚本自动准备非 root 服务、私有 PostgreSQL、Nginx HTTPS 和证书续期，先在本机初始化管理员密码再开放公网入口。

## 部署与升级

- Windows amd64、Linux amd64/arm64、macOS Intel/Apple Silicon 均提供完整离线 ZIP。现有安装需按升级手册备份并使用应用内更新，不要用新包直接覆盖运行中的数据库。
- Linux VPS 安装只支持全新 Alibaba Cloud Linux 3。云安全组必须预先开放入站 TCP 80（证书签发和续期）及 TCP 443（建议只允许管理员 IP），不要开放应用 5173 或数据库 5433。系统仓库、PyPI 和证书机构需要出站网络；应用本体及 PostgreSQL 运行时在包内。
- 原生 Linux/macOS 通用离线包仍可按 `README.txt` 由普通用户启动；VPS 单脚本专门解决全新公网部署场景，不能拿来迁移已有客户数据。
- 应用托管于 systemd 时，应用内一键更新后进程归属尚未完成原生验收，正式业务机暂勿执行此更新路径。旧密钥缺失不能通过版本升级恢复。

## 验证边界

- 本版源码测试、五平台构建及各包内外哈希以发布记录为准。Windows 上的交叉编译、安全解包和静态校验不能代替全新 VPS 上的证书、登录、服务重启或续期验收。
- macOS Gatekeeper、客户历史数据库迁移、真实代理出口及报告保存的数据库集成测试仍需分别验收；本版不宣称这些场景全部通过。
- 仅在已授权范围使用，管理面公网入口应限制来源并保护管理员密码；私有目录 `.yunkun-local` 不得上传。
