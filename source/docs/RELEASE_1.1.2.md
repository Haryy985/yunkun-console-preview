# 云鲲 v1.1.2 离线版

基于 v1.1.1-offline，汇总此前本地验收版本及代理补丁。本次发布不是“所有历史问题全部解决”的声明。

## 更新与优化

### 代理池

- 默认按请求轮询同池合格节点；固定出口需手动选择。CONNECT/SOCKS隧道按新连接选点，已建立连接不强行迁移。
- 明确代理连接故障进入60秒持久冷却。自动模式下，无正文GET/HEAD和未建立的CONNECT最多尝试3个出口；固定模式不自动换点。
- 目标HTTP错误不直接判为代理故障；池内无可用节点时停止，不跨池、不回退直连、不自动重放写请求。
- 修复发现来源与目标池选择不同步、入池误用旧池、过期异步节点结果覆盖新选择，以及导入/发现接口笼统返回凭据错误。
- 不可解密池新增显式恢复：先暂停关联任务，再填写整组认证，或对固定地址池确认无认证。保留节点、绑定与旧密文备份，旧验证失效，重新验证后才能出网。
- 修复仅编辑名称等元数据意外改变凭据、旧成功回调清除新故障、恢复与任务操作锁等待、截断响应误记成功。
- 手动固定/重分配排除冷却、过期和验证不合格节点；未选节点不能提交，换池清除旧选择。

### 更新下载与多平台升级

- 校验清单/完整包优先使用GitHub资产API，受信任发布链接回退；TLS失败受控重试，显示下载进度。
- 同次更新中的中断下载按有效Content-Range续传，仍验证完整SHA-256；错误分段、大小或哈希不会安装。
- 更新支持系统HTTPS_PROXY/NO_PROXY；显式代理优先，配置错误不会静默改为直连。
- 备份边读边计算源哈希，目标仍独立校验，减少重复I/O；下载/校验失败不会停止旧服务或修改旧数据。
- macOS Intel/Apple Silicon接入与Linux共享的受管升级事务：预检、停服停库、备份、迁移探测、启动检查与失败回滚。
- 增加OS/CPU候选校验、macOS启动文件白名单和进程身份验证，避免误停无关进程或安装错误架构。
- 发布流程隔离简版自动包与完整离线包，防止同一标签的SHA256SUMS被另一条构建链覆盖。

### 报告、审核与任务缓存

- 导出失败显示实际HTTP状态、接口和质量阻断原因；409不再仅显示笼统失败，也不会绕过质量门禁。
- 429按Retry-After等待后允许手动重试，缺省等待30秒；防重复点击，不自动重放，不将错误响应下载成报告。
- 切换任务取消旧报告请求，避免旧结果覆盖当前页面。
- 审核详情显示模型裁决耗时，区分模型等待与人工待审批，不放宽安全拦截规则。
- 主Agent、规划、Worker和会话Agent提供受管cleanup_task_cache：仅预览/清理各自cache目录，校验范围、链接及文件变化，不删除已存证据或旧任务根目录。

## 升级注意

- 完整包支持Windows amd64、Linux amd64/arm64、macOS amd64/arm64。包含程序、内嵌页面和PostgreSQL运行时；不需要Go、Node或Docker来启动控制台。云模型/API、网络和可选外部工具仍需自行配置。
- Windows运行setup-and-start-offline.bat；Linux运行bash start.sh；macOS运行Start-Yunkun.command或bash start.sh。首次设置自己的密码。
- 升级前暂停任务，保留数据库、配置、jwt.key、proxy-pool.key和自定义Skills完整备份；不要把新包直接覆盖正在运行的旧安装。
- 旧版macOS没有更新能力，首次需要按升级手册迁移；发布新包不能自动给旧程序补上升级代码。
- 旧版未记录历史节点绑定是否为用户主动固定，本版默认迁移为轮询；需要固定出口的任务请暂停后重新设置。
- 旧密钥缺失不能靠更新还原，池凭据恢复不等同于恢复FOFA/Quake来源Key。来源认证需分别重新配置。
- 客户需首次成功升级到本版，后续下载才会使用新的下载逻辑；不能保证旧版第一次下载不再超时。
- 发布包不含维护者的账号、Key、数据库、任务或日志。运行后的.yunkun-local是用户私有数据，不应再分发。
