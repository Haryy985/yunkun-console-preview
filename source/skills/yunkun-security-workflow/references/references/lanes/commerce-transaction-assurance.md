# Lane · Commerce Transaction Assurance

## 适用信号

- 商品、购物车、订单、支付、优惠券、积分、库存、发货、退款、售后、结算。

## 先画交易状态机

用一个可清理的测试订单记录商品/价格快照、优惠、库存、支付状态、订单归属、发货或退款的真实顺序。金额、前端折扣展示或 `success=true` 都不是结论，必须观察服务端持久化状态。

## 高价值分支

- `order-ownership-lifecycle`: 详情、取消、地址、发票、物流、退款和附件是否绑定同一订单归属。
- `price-coupon-state-consistency`: 价格、优惠、积分、库存、支付与退款是否在每一转换重新校验。
- `payment-callback-binding`: 支付回调、订单号、金额、币种、状态和通知是否被一致关联。
- `refund-role-boundary`: 客服、商家、用户和自动任务在退款/售后状态上的权限是否一致。

## 默认不做

不构造真实资金损失，不批量创建订单，不用并发代替状态机证明。优先使用测试订单和最小可回滚状态。
