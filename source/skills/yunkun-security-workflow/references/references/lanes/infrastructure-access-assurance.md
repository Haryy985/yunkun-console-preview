# Lane · 基础设施访问面 / 远程接入

## 适用信号

- SSH、RDP Web、Jumpserver、堡垒机、VPN/SSLVPN、远程桌面网关、防火墙/路由器/交换机 Web 管理面、网络设备控制台、运维审计、会话录像、文件传输、命令执行入口。

## 先建模什么

- `access chain`: 入口、身份源、MFA/验证码、目标资产列表、会话建立、命令/文件/审计链。
- `actor`: 操作者提供的测试账号、普通用户、审计员、运维、管理员。
- `asset boundary`: 主机、系统、项目、环境、网络区域、协议。
- `operation boundary`: 登录、列资产、发起会话、命令执行、文件传输、录屏/日志查看。

## 最小验证链

1. `authorized-pentest` 使用操作者提供的测试身份；`adversary-emulation` 可按书面 ROE 对 in-scope 身份做有界候选验证、批量验证或密码喷洒，并由 `credential_guard.py` 强制预算、速率和并发。
2. 单变量：目标资产、角色、协议、项目、文件路径、会话参数或审计对象。
3. negative control：无权限资产、不存在资产、错误角色或已关闭协议。
4. 只有证明越过目标资产、角色、会话、命令、文件或审计边界时，才升级。
5. 登录页、产品版本、证书、Logo、默认提示、单次 401/403 只算 observation。

## 高价值分支

- Jumpserver/堡垒机：资产授权、会话共享、录像/命令审计、文件传输边界。
- RDP/SSH Web：目标资产选择、凭据代理、剪贴板/文件、会话恢复边界。
- 网络设备管理面：普通用户与管理员菜单、配置导出、只读/写入动作、备份文件访问。
- VPN/WebVPN：匿名/已认证资源边界、跳转服务参数、内部 URL 代理规则；按 webvpn lane 联动。

## 证据与停止

- 密码猜测、批量登录、外部候选列表和横向验证只能在 `adversary-emulation` 的明确 ROE 范围内执行；每一步都要保留范围、预算、速率、结果和停止条件。
- 会话建立、文件传输、配置修改必须有 before/after、最小样本与 cleanup。
- 缺少测试账号时只覆盖公开入口和认证边界，标记 `blocked` 后转向其他模块。
