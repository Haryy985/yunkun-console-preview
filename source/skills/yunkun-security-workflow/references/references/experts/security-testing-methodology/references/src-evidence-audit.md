# SRC 漏洞证据审计框架（外迁明细）

> 本文件为 `security-testing-methodology` §六 验证清单的完整明细（P3 治理 2026-08-14 外迁）。
> 正文只保留摘要与指针；提交 SRC 前按本文逐项执行。

## 候选分类与验证协议

| 候选类型 | 典型例子 | 核心验证问题 |
|:---------|:---------|:-------------|
| **公网暴露** | 内部登录页/管理后台公网可达 | ①仅静态登录页？②前端初始化泄露敏感数据？③未登录可调业务API？ |
| **权限泄露** | OIDC/API Scope 名称含高危权限 | ①普通客户端能请求该Scope？②Token 真实包含？③资源服务器接受？ |
| **WAF绕过** | 大小写/编码/header 变异致状态码不同 | ①两路径到达同一应用？②绕过后获得数据/功能？③后端大小写敏感？ |
| **信息枚举** | 错误码/响应时间/状态码差异 | ①差异稳定可复现？②泄露敏感数据？③可致 OAuth 攻击/授权绕过？ |
| **状态码差异** | 不同参数返回 200/403/500 | ①差异来自应用层而非 WAF/CDN？②可稳定推断敏感信息？③可进一步利用？ |

## 证据矩阵（强制性，提交前每个候选项必须填写）

| 字段 | 内容 |
|:-----|:------|
| **资产** | 完整域名+路径+接口 |
| **SRC 范围状态** | 明确在范围 / 无法确认 / 第三方资产 |
| **安全边界** | 登录/角色/租户/客户端/VPN/网络边界 |
| **当前已确认事实** | 只填实际观测到的结果，不要推测 |
| **漏洞假设** | 想要验证的具体安全问题（一句话） |
| **对照组** | 正常请求与异常请求如何比较（必须设计对照） |
| **最小验证步骤** | 非破坏、可重复的操作 |
| **实际结果** | 状态码/响应关键字段/权限差异 |
| **预期结果** | 正常安全设计应该如何处理 |
| **安全影响** | 数据/功能/身份/权限方面的实际后果 |
| **是否可提交** | GO / HOLD / NO-GO |
| **缺失证据** | 仍然需要确认的内容 |
| **停止条件** | 何时立即停止继续测试 |

## 严重程度判定规则（不得依据系统名称/内部属性/品牌提高等级）

| 等级 | 判定条件 |
|:----|:---------|
| **信息/低危** | 内部域名出现在JS / 登录页公网可访问 / OIDC discovery 与 JWKS 公开 / Scope 名称可见但无法获得权限 / 通用错误信息 / 路径大小写状态码不同但未访问受保护资源 |
| **中危候选** | 未授权读取有限但明确的内部业务数据 / 稳定用户/应用/租户枚举并有实际影响 / 普通用户可访问不应开放的内部接口 / OAuth 回调校验不严 |
| **高危候选** | 未授权读取大量敏感数据 / 跨用户跨租户越权 / 普通账户获得管理员能力 / OAuth/OIDC 缺陷致账户接管 / 未授权执行核心业务操作 / 公网访问直接突破身份或 VPN 边界 |

## 控制组对照测试

任何「响应差异」验证必须有对照——已知有效参数 / 随机无效对照 / 空值对照 / 无参数对照。判定：有效与无效相同错误 → 无枚举；不同错误且差值含敏感数据 → 泄露候选；差值仅通用文本 → 无损枚举，影响极低。

## 最终输出结构（只输出三部分）

① **结论摘要**（GO/HOLD/NO-GO 按优先级）；② **最强漏洞证据包**（GO 项：标题/资产/前置条件/最小复现/关键请求与脱敏响应/实际影响/预期行为/修复建议/严重程度与理由/测试边界与停止位置）；③ **下一步只读任务**（≤5 个，按收益/风险排序：目的/对象/只读方法/成功判据/失败判据/停止条件）。
