# 34 · SRC 提交前审查与平台适配

## 提交前五问

1. 资产归属能被审方确认吗
2. baseline / variant / negative 完整吗
3. 对象归属与最终状态完整吗
4. 影响表述是否只写已验证能力
5. 这条报告是否有明显重复/信息不足风险

## 平台适配

### SRC / EduSRC

- 更重视资产归属、账号归属、对象归属、业务影响
- 标题直接写根因 + 影响，不写营销词

### CNVD

- 更重视通用性、产品/组件、版本、部署条件、复现稳定性
- 没有通用性时不要硬套 CNVD 口径

### 众测 / 赏金

- 更重视可复现性、独特性、影响清晰度、低噪声
- 重复风险高时先做差异化说明

## 标题模板

`[主体/系统] [边界失效类型] 导致 [已验证影响]`
