# 35 · SRC 提交反馈学习

## 每次提交后都要记

- `accepted / duplicate / informative / n/a / no-impact / out-of-scope`
- 驳回原因
- 缺失的是哪一层证据
- 哪个假设高估了
- 哪个专项最有产出

## 回写字段

```text
submission_outcome
rejection_reason
missing_evidence_layer
overstated_claim
winning_signal
losing_signal
next_bias_update
```

## 学习原则

- 被拒不是结束，是负证据
- 负证据会降低同类信号初始分
- 被接受的链路会进入 experience replay
