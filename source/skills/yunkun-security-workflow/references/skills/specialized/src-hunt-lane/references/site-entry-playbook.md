# 进站打法（dig-scope §4 提炼）

> 源：clown dig-scope-workflow.md §4（单站主路径全量细则）。

## 4.0 进站先说清这摊（防空扫）

清单前用 3~5 行写清（禁写成作文）：
- 谁在用（C 端/商家/运营）
- 核心对象（订单、工单、券、文档…）
- 钱、权、状态落在哪几个字段
- 没登录能碰到哪一层

说不清就先抓包补，不许空着开扫。看见小程序/APP/GraphQL/WebSocket/批量导出/Agent 工具/模板预览/文件转换/命令 RPC → 当本站面跟。H5 墙后包里的 `appId`/小程序网关/客户端盐，按本站钥匙用。

## 4.1 建接口清单 + 抽钥匙

JS **不只抽 path**：

| 抽到什么 | 干什么 |
|----------|--------|
| `/api/` 路径 | 进清单 |
| 签名盐、硬编码钥 | 自己算，打「只要 sign、不要 Cookie」的口 |
| 密文 id + 前端公钥 | 自己加密邻号再换（idor-test.md） |
| 异步 chunk、sourcemap、hidden/admin 路由 | 页面不展示也直接打对应 API |
| 写死的演示号、测试租户 | **当钥匙用**（与登录框喷 admin/admin 不是一类） |
| 会跑命令/渲染模板/表达式/RPC/Agent 工具 | 进清单并开对应模块；没有写「无」 |

降级：纯 API → Swagger/抓包/响应 link/常见网关 path；打开是登录页 → §4.1.1；JS 下失败 → 抓包+HTML 内联+已知 path，禁空等；无对比账号 → 没号走未授权+换 id，不为第二号磨注册。

## 4.1.1 打开是登录页（自由跳默认未登录）

**禁止读成「登录相关一律不管」。** 不管的是表单上的验证码、默认口、无限试。空密、跳步、改响应、JS 钥匙、登录接口上的 `tenant`/`moduleId`、旁边露出来的名单/详情，看得见就打。

先找业务面（不用登进去）：`service=`/`redirect_uri=`/`callback=`/`jumpUrl=`/`next=`；JS/`env.js`/`baseURL`/`apiHost`/`/prod-api`；302 Location；同品牌 `api`/`admin`/`gateway` host。业务面可能是另一个 host，也可能是本 host 登录后面的网关。

| 看得见就打，打通或证伪就停 | 不打/不当进度 |
|---------------------------|----------------|
| 空密、跳过密码步、改响应能进 | 验证码 OCR、滑块、默认口字典、无限试密 |
| JS 硬编码钥匙 | 对用户名/密码框灌注入充四件套 |
| 登录接口上业务字段（`tenant`/`corpId`/`moduleId`）按注入打 | 同皮登录表单再挖一遍 |
| 登录旁边已露出的业务 path 未授权照打 | 401-403-bypass 磨登录 HTML；审别人的 IdP |
| 中间件裸默认口（nacos 等）可一眼 | — |

**看见登录页不是换资产。** 只有跳转/JS/配置里一个业务面都抽不出、旁边也没有未登录业务口、清单也没有认证口 → 才记空壳换下一条。进了会话（用户给号/JS 演示号/空密打通）→ 立刻转 §4.2.3 对象图，不要还对着业务口打引号。

## 4.1.2 业务口全是同一登录码（同闸停）

| 回包长什么样 | 算什么 | 干什么 |
|--------------|--------|--------|
| 通篇就一句「请登录/NotLogin」，没有 list/total/业务字段 | 登录闸 | 四件套整段 N/A，别丢 `'` |
| 有 list/total/业务字段，哪怕 total=0、数组空 | 有差分面 | 还得测（换参、换 id、注入） |
| 报错、500、超时、长度/耗时明显不一样 | 有差分面 | 还得测 |
| 缺个参数却吐出名单/详情 | 未登录例外 | 按 §4.2.1 打 |

**空列表是「出了结构、条数是 0」，不是请登录。** 同闸 = 业务 path 已抽出 + 未登录例外已点过 + 其余口同一家族回码 + 没有未登录出他主体。然后停这个闸：四件套对着同一登录码可以停；清单里还有认证口（§4.2.2）没勾 → 先收这组再记 done。同产品下一 host 还是这套 baseURL+同一回码 → 一眼差分（JS 有没有新 path/回码变没变）。

## 4.1.3 回包当线索

回包里新出现的 id/下载地址/token/内部 host/角色字段 → 立刻进本站清单再打。列表过了，附件和导出还要打一枪（父对象过了鉴权、子对象常没过）。

## 4.2 全类型矩阵（禁偏科）

与 value-matrix.md 并集。力气先砸哪认 value-matrix §1.1：未登录他主体 > 认证接管 > 换 id > 有号写/逻辑 > 四件套打在已出数业务参上。

### 4.2.1 硬四件套不得连日空窗

| 类型 | 必须做的探针（有入口时） | 无入口才可 N/A |
|------|--------------------------|----------------|
| **注入** | 能看出条数变、内容变、会拉网址的口：每个查询/过滤/排序/关键字参数都测（基线→探针→差分）。**按栈选探针**：JSON/Mongo 打 `$ne`/`$gt`；搜索框打 ES DSL 或列表 OR+total；Java 打 HQL/SpEL；有模板打 SSTI；SQL 面走 `'`/布尔/延时（按库）→ WAF 编码 `%0a` `%0d` 双写 注释 大小写 → 换位置 query/json/header/path。用户名/密码框不是业务参；登录接口上的 `tenant`/`corpId`/`moduleId` 有就打 | 纯静态页无业务参；仅登录框；回包只有登录码 |
| **SSRF** | 所有 URL/回调/webhook/file/fetch/import/preview/proxy 类参数：内网、云元数据、外带 DNS/HTTP；打自己监听看回显 | 清单与抓包里零 URL 拉取/代理类字段 |
| **XSS** | 反射：参数回显处打标签/事件；存储：能写的昵称/备注/留言/文件名再读回；结合是否无登录可读 | 无回显、无用户可控写入点 |
| **RCE 链** | 有命令/表达式/模板/反序列化/调试执行/危险上传入口就跟到执行或证伪；半条链继续跟 | 清单+抓包+回包都没有这类 Sink（后来回包冒出 exec 立刻补打） |

勾完 = 有差分面参数打穿或证伪。硬禁：连日空窗（连续多轮只有未授权读/列表，四件套没对真实参数发过 payload）；假进度（findings 写已测但参数表空）；偏科节奏（未授权写完就换站）。

### 4.2.2 任意登录 / 账号接管（有入口勾完）

挂在「认证/会话」，不是第五件套。表单壳停了 ≠ 这些口不用打。

**安全红线（写越权最小伤害 · 不可违反）：**
- **默认**用读/列表差分证明跨用户·跨租户（优先 GET/查询）。写越权仍要测，不是"一律不许写"
- 顺序：**先添加**（看能不能挂到别人名下）→ **再删除自己刚加的那一条**。不改/不删别人已存在的订单、地址、密码、角色
- 没有创建口只能动现成对象时：只改自己能改回去的测试字段，打一次。改密/改角色/改绑拿掉旧验看 过不过（过了立刻改回；改不回停在回包，不要把用户号的密/角色/邮箱留下）。扣钱、清库存不做。禁止批量、禁止真资损
- 禁止把「只读红线」理解成「写 IDOR 不用测」

**没号（每枪一次，进了或明确不行就下一项）：**
- 任意登录：空密/请求删 `password`；跳过密码步直接打真正发 Cookie/token 的口；改响应 `success` 且看有没有真会话；JWT `none`/硬编码钥/客户端造票；自家换票、callback、绑定时改 `uid`/`openid`
- 接管：重置/验码回包里有没有 token 或码；有则拿去登录或走重置最后一步；最后一步把 `uid`/`email`/`phone` 换成别人的；能构造两个身份时 A 的码填到 B

**有号：** 认证口仍按「自己的会话 + 换别人身份」打。改绑手机/邮箱：拿掉旧密码旧号验证（过了改回）；改密：不带 `oldPassword`（过了改回）；重置最后一步身份换成别人的（动别人的 uid，不是把用户自己的密改掉）；业务对象上的越权/逻辑走 §4.2.3。

**安全红线：** 禁止调 `/logout`/`/signout`/`/revoke` 及一切退出/注销/吊销；不测「退出后会话还在不在」（那一枪必须登出）；改绑/改密过了立刻改回原值；改不回去的只看回包是否接受就停；不在用户号上真改邮箱测旧重置 token；保持用户会话始终有效。

### 4.2.3 换 id / 对象图（没会话 ≠ 不换 id）

换 id = 能圈谁、圈哪条、哪个租户、哪个文件的参数都换，**不限字段名**。

| 有就打完 | 无入口才 N/A |
|----------|----------------|
| **对象图**：列表→详情→附件/导出/审批，每层换 id | 纯登录墙、抽不出对象 |
| **圈人圈数的参**：邻号/回包里抄的/`0`/`-1`/空/复杂包里圈人的 | 一个可换的都没有（单号也先抄，不准直接放弃） |
| **写接口**加 `role`/`isAdmin`/`amount`/`status`/`vip`（多赋值得手再打穿；只改能改回去的） | 没有写接口 |
| **多步流程跳步**；领取/库存/券/审核 → 并发一枪 | 没有这类口 |

禁止为凑第二个号去磨注册/验证码。缺对照：用邻号和回包里的 id。

## 4.3 本站「本轮完成」= 可换站下限

1. §4.0 已写（或确认抽不出业务对象才记空壳）
2. 接口清单已建（默认或降级；钥匙表抽过，无则写「无」）
3. 类型矩阵探针勾完（无入口 N/A+原因，禁空话）
4. 高价值接口参数矩阵已覆盖
5. 打成了按 src-report-paradigm 落 `报告/`（无洞不写空报告）
6. 未耗在同皮镜像/已 covered 号段
7. 登录页：业务面已找到并挖过未登录（或确认抽不出才记空壳）
8. 同闸：未登录例外已点、四件套收口、认证口勾完再 done
9. 认证口：清单里有发会话/重置/改绑/换票/2FA → 探针勾完或 N/A。有口零 payload = 漏测
10. **中危已落盘，同一对象还没走到「能写/能看别人/能接管/能执行」→ 先升链不换站**。文件通道通了转业务
11. 肥瘦分层：肥面（JS 多/后台/业务 JSON）打到对象图+有差分参；瘦面（403 空壳/同闸/同皮无新 path）一眼证伪记过，不占满 15 分钟

高价值苗头先打穿再换站：稳注入/RCE 链/跨租户/未授权敏感读/可用凭证（认钥+只读例）/任意登录进号/接管改密改绑。看见登录页不是换线理由；站不可达/人机死挡无替代/纯废壳 → 记过换站不提问。
