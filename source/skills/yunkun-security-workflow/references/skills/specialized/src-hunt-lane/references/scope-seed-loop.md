# 范围与种子循环（dig-scope §0-§1 提炼）

> 源：clown dig-scope-workflow.md §0~§1.5（2026-08 版）。本文件是 src-hunt-lane 的自由跳/锁面全规则。

## 1. 锁面口径（防锁太死）

| 锁（禁止） | 不锁死（必须挖） |
|------------|------------------|
| 未进站就 FOFA/爆破扫全集团、无关事业部 | 入口自带/加载出的多个 host → 都挖 |
| 擅自跳到与当前资产无关的旁系域名 | 登录/点功能后子域、网关、API 域切换 → 跟业务流 |
| 文档当自由跳种子扩集团 | 同 host 多 path/接口全展；JS/配置带出的同产品业务 host 纳入本轮 |

**锁面清单顺序（硬）：** 用户标了「重要资产/优先」→ 先打那一组；「一、二、三」不是必须从上往下清完；同皮只留 2~3 代表（登录壳同皮 → 登录表单不用再挖，只比 `jump`/`service=`/`moduleId` 是不是另一个业务面）。锁面结束：资产簇本轮矩阵做完可停或短报。

## 2. 种子分层

| 优先级 | 类型 | 策略 |
|--------|------|------|
| P0 | 用户点名业务、SRC 公布域/业务线、在用知名产品根域 | 直接 FOFA；仍要去废 |
| P1 | 企查查/证书常见、标题/org 常撞品牌的域 | 秒级活域过了再 FOFA |
| P2 | 大批 ICP 主域、历史壳域 | **必须先活筛**；不过不送 FOFA |
| 废/cold | 死备案、纯停放、无解析 | 本轮不碰 |

## 3. 备案长尾活筛

```
备案长尾 d:
  1) 根 DNS？无 → 不立刻判死，先做 3)
  2) 根/www 短超时探 80/443 → 有业务味升活；停放/连不上 → 进 3)
  3) crt/被动子域 → 有用子域升活；0 且根/www 死 → cold
  4) 有配额可选 domain 条数探针；无配额跳过
  5) 通过 → 正式 FOFA → 去废 → 挖
```
仅根/www 连不上必须再查 crt/被动子域；仅 401/403/登录墙 = 算活。FOFA 已搜仍快弃：空/全 CDN 默认页/标题同质停放/与品牌完全不沾 → 立刻换下一个。

## 4. 优质根域回灌（§1.1.1）

- 确认优质面（业务面大/JS·接口多/登录后台/业务 API/Swagger）→ **立刻**把向上归约的搜域 R（业务簇根/品牌根，非叶子 host）写入种子队列 pending
- **本种子剩余活面全部挖完之后**才优先 `domain="R"` 再搜；无相对 covered 新增 → 立刻跳下一 pending
- 不回灌：废壳/CDN/第三方/参股/队列已有该 R/同簇 R 已存在
- 禁止：叶子 host 条条刷 FOFA；回灌后不去废全挖；本种子还剩活面就去搜 R

## 5. 续挖 / 新开 / 全做过

- **旧夹还在（续挖）：** 进既有任务夹；起手读 covered_hosts + 种子队列 + 报告/ + dig STATE；跳过 done/cold 种子与 covered host；同 host 新 path/新端口/新应用仍测
- **旧夹已清（新开）：** 新建队列；种子按 §2；顺序可洗牌
- **全做过仍未叫停：** 随机补关键词再搜（默认先走）或回扫旧种子（抽查不是流水线）。回扫合格闸：先有新增证据（新 host/新 path/新端口/JS 哈希变且抽出新 API）才进站；本回合连续 2 个回扫 0 新增 → 下一槽必须随机新业务名

## 6. 种子队列落盘

`资产/种子队列.md`：| 种子 | 类型 P0/P1/P2 | 状态 pending/doing/done/cold | 备注 |

```
pending → doing → 只搜这一个 S → 清洗 → 剩余活面全部挖完 → done/cold
本种子剩余活面没挖完 → 禁止取下一条 pending 去 FOFA
done 后同一轮工具循环内立刻取下一条 → 再走同一闭环
全 done 且未叫停 → 随机/回扫，不是停工
```

**词义防呆：** 「本种子收工」= 只结束当前种子或当前站，立刻换下一 pending；「一轮 FOFA 搜完」= 这一种子检索结果已捞齐，进入清洗+挖，还不能搜下一个种子；「分批 FOFA」= 这一种子的结果翻页。

## 7. 测绘引擎配额（FOFA/鹰图通用）

- 有配额：只搜当前这一个种子（结果可翻页）
- 没配额（FOFA 429/820041；鹰图 code 402/积分不足）：停测绘空刷（含活筛条数探针）；挖本种子已入库剩余；P2 活筛改 DNS+HTTP+crt
- 补池仍须去废+去非存活+股权闸：crt.sh、subfinder、进站 JS 抽出的范围内业务 host、SRC/企查查新业务名
