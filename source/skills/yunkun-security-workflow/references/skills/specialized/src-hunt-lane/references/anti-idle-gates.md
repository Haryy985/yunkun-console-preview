# 反空转与深挖优先闸（dig-scope §2 提炼）

> 源：clown dig-scope-workflow.md §2（2026-08-07/08-16 版）。用户不应靠「很久没新报告」才发现空转——Agent 必须自检纠偏。

## 1. 空转信号表（命中即纠偏）

| 信号 | 含义 |
|------|------|
| 长时间 `报告/` 不增 + 只堆 403/health/重复 path | 空转 → 换本种子下一条活 host（不是开新种子搜） |
| 瘦壳（403、无业务 script、同闸）>15~20 分钟无苗头 | 杀这条线换下一条；**肥面**（JS 多/后台/业务 JSON）还在抽 chunk/建对象图 = 干活不算空转 |
| 一种子/一轮 FOFA 完就停 + 问继续 | 违规收工；FOFA 完应进入清洗+挖 |
| 多种子一次搜完 / 本种子还剩活面就开下一种子 | 违反一种子闭环 |
| 旧夹还在却从零开、不跳过 covered | 违反复用 |
| 全 done 后空等 | 违规；走随机/回扫 |
| 连续回扫已 done 种子、umi 未变仍全矩阵 | 回扫工厂；下一槽改随机新业务名 |
| 队列未落盘或只有用户原词 | 必漏品牌/域名 |
| 回复以「要不要继续/换品牌」收尾 | 黑名单句式 |
| 只搜用户原词、能建的种子也不建 | 漏面 |
| 参股公司当集团资产深挖 | 违反股权闸 |
| FOFA 429/820041 仍刷 | 配额尽空撞 |
| 有前端无接口清单盲扫；类型只测两三种 | 假进度/偏科 |
| 同皮登录墙反复验证码/默认口 | 空转 |
| 看见登录页就换下一家，业务 API 还没挖 | 违反登录页规则 |
| 清单有发会话/重置/改绑/换票，零 payload 就换站 | 漏测 → 先补探针 |
| 业务口全同一登录码，还对同产品下一 host 再开全矩阵 | 同闸连磨 → sibling 一眼差分 |

## 2. 什么算/不算进度

**不算进度：** FOFA 条数、探活计数、假中间件、纯文件通道 up/down、已落盘报告再确认一遍、CORS、纯登录码上把四件套勾完、每个 path 喷过 `'` 但没有差分面。

**算进度：** §4.0 几行说清这摊、接口清单（或合法降级）、回包线索进本站队列、业务 JSON 上的全类型矩阵、有差分面的四件套、认证口勾完或 N/A、有会话的对象图/换 id、正式报告落盘、未登录例外打穿或证伪。

## 3. 深挖优先五闸（只纠节奏不砍能力）

**闸 A — 本种子还剩未挖活面 → 停开新种子 FOFA**
命中任一条 → 本轮禁止再 FOFA 新种子/新关键词：① 当前种子清洗后还存在未挖/未记废的活 host ② 近 15 分钟主要在扩面/探活而清单未建且报告无增。
仍允许：本种子结果翻页；本种子挖完要换种；用户点名换线；全 done 后随机/回扫。

**闸 B — 未「本轮完成」禁止拿新词 FOFA 充数**
当前站未达进站下限时，禁止「先再 FOFA 一波」当主动作；必须先说清这摊→JS→清单→矩阵→落盘/证伪。高价值苗头（稳注入/RCE/跨租户/未授权敏感读/可用凭证/任意登录进号/接管改密）先打穿再换站。

**闸 C — 优质关键词/搜域 R：只回灌不改道**
优质词立刻写队列 pending；当前矩阵继续；仅当本种子挖完才搜 R；禁叶子 host 条条刷 FOFA、好词只在对话里提不落盘。

**闸 D — 测绘配额尽（FOFA 429/820041 / 鹰图 402）→ 强制挖池**
可切备用 key 补当前缺口；全 key 皆限 → 整轮禁再测绘，只打已入库 + JS/crt 补 host。禁限流时空等、把换账号刷条数当进度。

**闸 E — 多线程：深挖为主，禁双 FOFA 工厂**
深挖线程：指定 host §4.0→JS→清单→矩阵→报告。可选 1 条补面。禁 N 条线程都在 FOFA/探活而 0 条在建清单。FOFA 由主控短触发。

## 4. 能力边界（防误读成砍能力）

| 本节能约束（只管节奏） | 绝对不是这个意思 |
|----------------------|------------------|
| 本种子还剩活站时先别搜下一个种子 | 少建种子、给种子定上限 |
| 当前站矩阵没做完禁拿测绘充数 | 禁跟 JS 新 host、禁多 path、禁打穿高价值苗头 |
| 双线程不都当 FOFA 工厂 | 禁 2 线程同时深挖两个 host |
| 同闸停：sibling 不另开全矩阵 | 看见登录页就换；业务 API 不用抽；新 path 不跟 |

规则与现场冲突、或会漏洞时：以打穿与证据为准，本节约律让路给产出。

## 5. 落盘与 covered（让装忙无处藏）

```
{任务}_dig/{host}/endpoints.md   # 接口清单
{任务}_dig/{host}/matrix.md      # 类型矩阵；四件套有勾或 N/A+原因
js/{host}/                       # 全量提取 JS
```
写 covered_hosts = 已过进站下限，不是「curl 过首页/FOFA 见过」。进度三硬件（15~20 分钟心跳）：① JS+清单有推进 ② 有差分面的四件套有真 payload 或 N/A ③ 报告新增或矩阵收口。三件皆无却只见 FOFA/探活计数 → 强制闸 A。

## 6. 收尾自检（发最终回复前，命中任一条禁止收尾停工）

1. 还有 pending？→ 禁止结束；标下一条 doing 继续
2. 刚 done 一种子？→ 禁止问继续；同一节奏开下一条
3. 全 done 且 covered 盖满？→ 随机/回扫；只有用户叫停才真停
4. 最后一句是「要不要继续/您指示下一步」？→ 违规，删问句换种子

**合法真停：** 用户叫停/清理/换目标/明确锁面；锁面簇做完；环境全线不可用且已试替代线后的极短报障。
