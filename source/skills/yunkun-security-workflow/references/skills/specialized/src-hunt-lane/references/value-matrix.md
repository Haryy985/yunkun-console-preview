# 价值导向与类型矩阵（src-value-hunting 提炼）

> 源：clown src-value-hunting.md（列表注入实战复盘版）。本文件管「挖什么、每类最低探针、力气怎么分」；落不落只认 src-report-paradigm。

## 1. 挖什么：真价值优先

有价值 = 能打到高危/严重那档：跨租户/跨用户读或写、未登录出业务敏感、低权到平台管理员、注入出他主体、完整链（跨用户写、进号、命令跑起来）。

**「管理员」语义：** 盯官方/平台级管理员权限是否可到 + 提权链；租户 ADMIN 是跳板视角（用本租户基线对比越权后是否变成海量/他租户），不是「当前是 ADMIN 所以能看的都不算洞」。

### 1.1 力气先砸哪

| 先打 | 说明 |
|------|------|
| 未登录出他人/他主体 | 不登录出名单/详情/附件。**未授权通了再换 id**（不限字段名） |
| 认证接管 | 发会话/重置/改绑/换票；进号或改密才算 |
| 换 id（不限字段名） | 没号：未授权通了再换。有号：带着会话换。他主体出现算打穿 |
| 有号写/逻辑 | 加 `role`、改金额/状态、跳审核、券/库存并发；盯租户身份能不能到平台管理员 |
| 四件套全硬 | 有条数/回显打注入；会拉网址打 SSRF；有回显/能存打 XSS；有命令/模板跟 RCE |
| JS 钥匙 | 盐、硬编码钥、演示号 |

**没号：** 未授权通了再换 id → 认证口 → JS 钥匙 → 有差分面的四件套（含 XSS）。
**有号：** 带会话换 id → 加字段/跳步/钱 → 四件套打在已出数业务参上。
**有入口仍测不当主业：** 只害自己的 CSRF（跨用户写成功仍跟）、能传能下没链、登录框弱口令。
**CORS 不挖**（SRC lane 内）。

## 2. 挖到这些别停在半截

- 文件通道开了 → 立刻转业务 API、可执行/路径/SSRF 链
- 发码接口通了 → 跟认证链：回包有没有码、码绑不绑号、重置换不换用户
- 滑块过了/能试密 → 表单壳停，打空密、跳步、重置、改绑
- DSN/配置只有 host 没账密 → 继续找完整凭据；有账密/AKSK 当钥匙打：假值对照 + 认钥枪带出身份或列表 + 不影响线上的只读例。抄到就停手交报告 = 禁止
- 本职可读、公开静态、接口 200 有 JSON → 转跨用户/注入/提权
- 回包里冒出 id/下载地址/token/内部 host → 进本站队列再打
- **中危落了先升链再换站**：同一对象还没走到写/跨用户/接管/可执行，先跟

## 3. 类型矩阵（每轮目标至少过一遍）

| 类型 | 探针要求（有入口就打完；无入口 N/A+原因） |
|------|----------|
| 未授权 | 关键读/写 `credentials:omit`。通了再换 id |
| 越权/IDOR | 没号：未授权通了再换 id。有号：基线→邻号/回包抄的 id/`0`/`-1`/空→附件导出。不为第二号停工 |
| 注入 | 能看出条数变、内容变、会拉网址的口：每个查询/过滤/排序/关键字参数都测（基线→探针→差分）。**按栈选探针**（JSON 操作符/ES OR+total/HQL/SpEL/SSTI/SQL 布尔延时）；WAF 编码+换位置。只回「请登录」无业务字段 → 整段 N/A |
| SSRF | 全部 URL/回调/webhook/file/fetch/import/preview/proxy 参：内网/元数据/外带 |
| RCE 链 | 命令/表达式/模板/反序列化/危险上传 Sink 跟到执行或证伪 |
| 凭证/密钥 | 假值对照，认钥枪须带出身份或列表，再打不影响线上的只读例。占位/过期/真假同一句 → N/A 不写 |
| 弱口令/默认口 | 中间件/组件裸默认口可一眼；打到真进会话。登录表单弱口令不当必做；JS/页里写死的演示号、测试租户**当钥匙用** |
| 敏感路径 | Swagger/Actuator/debug/heapdump/env；有没有密钥接着挖 |
| XSS | 反射（参数回显打标签/事件）+ 存储（可写点再读回）；结合是否无登录可读 |
| 上传 | 类型绕过、路径、可执行/SSRF 链；别停在能传能下 |
| 穿越 | fileKey/path/filename |
| CSRF/鉴权参数 | 无 ctoken/坏 ctoken + Cookie 属性；写操作是否成功 |
| 提权/逻辑 | 写接口加 `role`/`isAdmin`/`amount`/`status`/`vip`（只改能改回去的）；多步跳步；钱/券/库存改小改负改小数；领取/审核并发一枪 |
| 认证/任意登录/接管 | 清单有发会话/重置/改绑/换票/2FA → 按 site-entry-playbook §4.2.2 勾完 |
| CORS | **N/A · 不挖** |
| 其它现场面 | 矩阵未点名的现场面照样测 |

## 4. 接口与参数：禁止漏字段

1. 打开真实页面 → 抓**完整**请求（query + body）
2. 列出全部 filter/id 字段，**短枚举字段也要测**（如 `vote`、`answerType`、`status`）
3. 有差分面的口上，每个过滤参最低矩阵：正常值/空/非法值 → 按栈选探针 → 延时（按库型）→ WAF 编码 → 换位置
4. **差分是硬证据**：本租户基线 total/条数 vs payload 后 total/他主体字段

**教训实例：** `keyword=1%0aor%0a1` WAF 可绕，total 从 2 → 数千万级，跨租户元数据 → 真 SRC 点。漏测原因：只验「有没有数据」，没做「全参数注入矩阵」。

## 5. 执行节奏

1. **资产齐套**：域名、登录态、菜单路由、JS 抽 API（含盐/密文 id/hidden 路由/演示号）、真实请求参数表；回包里的 id/url 补进清单
2. **价值排序**：按 §1.1 先打未登录他主体/认证接管/换 id/四件套（含 XSS）；信息泄露后置且降级表述
3. **类型扫全 + 参数扫全**（有差分面优先）；新接口入队即测；CSRF/能传能下/登录框弱口令不当主业
4. **只留可复核证据**（请求、差分表、关键字段）；不堆无效「收获」
5. 打成了按 src-report-paradigm 落盘；中危同一对象先升链

## 6. 自检（交结论前）

- [ ] 有差分面的口上，是否每个 filter 参数都做过注入/越权差分？只回「请登录」的有没有误喷？
- [ ] 未授权是否用 omit 测过（业务接口）？
- [ ] 跨租户/他用户是否测过（不是只测本租户 ADMIN 可读）？单号是否用回包/列表里的 id？
- [ ] 有会话时对象图/换 id/加字段/跳步是否打了？
- [ ] 上传是否跟到可执行/SSRF/业务越权，没停在能传能下？
- [ ] 发码/滑块之后认证链是否按 §4.2.2 打过？
- [ ] 「管理员」是否误判成「权限内不算洞」？
- [ ] WAF 405 后是否换编码/换参数位置再试？注入是否按栈选了探针？
- [ ] 有无误挖 CORS？
- [ ] 本轮是否偏科只挖未授权读？是否每个 path 喷 `'` 充四件套勾完？
- [ ] 中危落了同一对象有没有先升链？回包线索有没有进清单？
- [ ] 抄到的凭证是否假值对照、认钥枪带出身份或列表、有不影响线上的只读例？
