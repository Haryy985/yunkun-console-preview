# shortlist（索引）

> 进站先看本表；对得上再打开「见 xxx.md」看细节（文件不长可整篇开，超长篇可先开点名节，不够就继续开）。禁止每站通读整库。进/补本表只认磁盘 `hunt-iter.md`（rules 目录；只增强、不限制）。改本表前必须先读该文件现稿，禁止用会话旧副本。
> **本表 ≠ 本站清单。** 打完开场几枪立刻回 `dig-scope` §4：先说清这摊、JS 抽钥匙、回包进队列。没号打有差分面的四件套；有号先对象图/换 id（§4.2.3）。进站仍过全类型矩阵：越权/未授权敏感读/逻辑/凭证/弱口令/认证会话/上传链… 现场有什么打什么。注入 / SSRF / XSS / RCE 是「有差分面必须真打、不得连日空窗」，**不是**只测这四类，也不是每个 path 喷 `'`。表上没有的手法照样挖。
