> **2026-08-19：** 迭代规则就这两部分。  
> **以后迭代规则只改本文件这两张表。** 加、减、改都在这里；禁止再把三问 / 不等「放」/ 谁写短表抄到 Agents、skill-as-boost、desktop。  
> **2026-08-24：** 门槛只指向 format（对正文、不抄定级条文）；太窄跟三问①②对齐，取消换站数量档；中危不开模块口。

## 一、干什么

| 块 | 规则 |
|----|------|
| 定位 | 表上没有照样挖。现场和表打架听现场。进站认到熟面孔可先看短表当开场几枪，对不上或已修就丢掉表按现场挖。认到框架/参数只加速当前站，禁止认到就 FOFA 全网同皮、打断一种子闭环。`*src经验.md` / 穷尽簇 = 放弃信号、假点，不是这个根域永不看新 path。 |
| 落哪 | 步骤/编码/证伪/长链 → `~/.grok/skills/skill/knowledge-base/` 已有对应模块。一行手法或指针 → `knowledge-base/shortlist.md`。这次正式报告（中危也写这里，只是不进短表）→ `Desktop\{任务}_SRC挖洞\报告\`。这次 URL / 提取 JS → 任务根 `资产/`、`js/`。任务根禁止复盘.md / 经验.md。写短表或改一行指针不超过半分钟；写不成形 → 不写，继续挖。 |
| 门槛 | 进的是手法，不是这个洞、不是某个 host。**过门槛** = 打开磁盘 `vuln-report-format.md`「漏洞等级」那一格，拿这篇**正文里做成了啥**对照那几条；不以标题或已写的「高危」二字为准。读磁盘 format 现稿。本文件不抄、不改那几条，也不再评一次等级。一条都没中 → 这篇当没高危，不进表。高危 ≠ 通行证。自己挖的：来源必须是已落任务 `报告/` 的高危或严重。用户丢进对话的：对话里要有能对照的报告/payload 正文（不必先落任务夹），仍按 format 对正文；只说「有个洞」、没有可对的正文 → 不进。中危只写报告，不进短表、不拟进。中危说放也不进。库里没有 ≠ 该进。本来不是洞、同构再确认、只有这次 host 的 path → 不进。 |
| 三问 | 过门槛之后才问，答不出或否定 → 不进表、不问用户。① 换一个站或换一个同形态产品，还能认到 A、按 B 去打吗？② 认的是不是只有这个 host / 这一条 path / 某一个产品里的字段名？换到同形态产品认不到同一套 → 不进（单站备忘；报告照写）。不是字段名黑名单：下次同形态还能认到同一套、差得出新认法，仍按三问进。②.1 无新认的通用枪不进：认的只是换 id、空密、omit、列表自增、每个 path 丢 `'` → 不进（这是 `dig-scope` 本分，不靠表里有没有才拦）。有新认（对照闸、编码位置、假点、打错会当没洞）才往下。认什么写成形态，禁止写成「又是换 id」或某个字段名。去掉这行、下次同类站还会按同一套打 → 不进；不会、因为要先认一个容易漏的形态 → 才进/补。③ 打开短表已有行：多出来的是新认法、新打法，还是新假点？差不出就不写；差得出且已有同类 → 只补原行，细节进模块。三问都过、库里没有同类、能写成「认 A → 打 B」、下次还有机会出高危 → 才加新行。证伪「以后会再当成洞」的形态 → 只改假点列。太窄见下一格，不并进本格。 |
| 太窄 | 见三问①②，不另立一档。换到同形态认不到的（这家特有接口名、延迟、活动号、死 path）→ 不进、不补。即使打穿了，也只是单站备忘。①已经放过的同形态不算太窄。禁止用「换 N 个站」「一条产品线」把 ① 放过的挡掉。已有行的新假点/新打法仍按三问③补，太窄不拦③。 |
| 两条线 | 本窗自己挖到并写下的：先过门槛，过了再三问。过了且库里没有 → 进短表，不等「放」、不问。已有同类有新差分 → 只补。门槛没过或三问不过 → 不写表，也不问。用户本人把报告 / payload / 手法丢进对话：自己先看懂。没有可对正文 → 不进。有正文则先过门槛（按 format 对对话里的正文），过了再三问。要进短表或补模块，都必须先过门槛。中危一律不补短表、也不补模块。「模块有新差分」只适用于已经过门槛的高危/严重：不够新开一行时只补原模块，不是给中危开口。过了 → 直接补，不等「放」，回一句懂/补了或懂/不补。只能害自己、半条链、同构无差分、网上通用 polyglot 重复、太窄、门槛没过、无新认的通用枪 → 不补。禁止高危一篇一行往短表塞。禁止把「等放」套到自己挖的洞上。 |
| 已有同类 | 思路已经在短表/模块里 → 禁止再开一行、禁止另起一篇。同构再打穿、手法没新差分 → 不动文件（报告该写还写）。认法/打法/假点/编码/证伪有新的能下次用的（换站还能撞上，不是这一家特有）→ 只补足增强已有那一行或那一篇：短表改同一行，细节并进原模块。新到已经不是同一「认 A 打 B」→ 才加新行 / 新指针。补的是手法差分，不是这个 host、不是这份报告摘要。认什么保持形态（框架/参数/业务面）；这家的产品名、完整 path、特有字段枚举进「打哪」或模块，禁止接到认什么后面当点名清单。算成只许写清楚或写严，禁止加更弱的「过签 / 缺参 / 鉴权过」当打穿。密钥实值、完整 JS 不补进库。这是增量补，不是整理旧库。 |
| 谁写 | 单窗（没拉子线程）：过门槛再三问，过后自己写/补。挖站子线程：禁止改 `shortlist.md` 和knowledge-base模块；高危落盘后在本站 `DONE.md` 写一行 `拟进：认…打…` / `拟补：哪一行多了啥` / `不进：门槛没过或三问不过或无新差分`。主控：子线程回来后先过门槛，过了再按三问复核，再写/补短表；DONE 不当knowledge-base。拉子线程时交付清单必须带迭代。禁止只写「JS + 清单 + 矩阵 + 落报告」。子线程开场读磁盘本文件，禁止只信会话里冻住的旧副本。 |
| 不挡换站 | 搜种 / 换站 / 换种 / 空转跳 / 一种子闭环只听 `dig-scope-workflow`。本文件管短表，不抬换站门槛。**中危先顺着同一对象挖大再换**（`dig-scope` §4.3）；并短表仍不挡换站。有高危报告 → 换站前花半分钟写拟进/拟补/不进；门槛没过或三问不过写不进就算迭代做完。主控并短表可以稍后，不挡走 `dig-scope` §4.3。高价值苗头打穿中途不写表，报告落了再先过门槛后三问。进/补短表不是收工。15～20 分钟空转：没高危就不要为短表耗着。无报告 = 无拟进。用户说清理：主控先把未并的拟进过门槛+三问，过了才并进短表，过不了丢弃，再删 dig。禁止等主控并完短表才换站；没出洞还磨拟进；把「缺迭代」理解成没并短表就不能走 §4.3；把「不挡换站」读成中危一写就换。 |
| 怎么读 | 省 token 是顺带，不是笼子。该开的模块、该看的细节必须开。进站：① 先读 `shortlist.md`；② 认到、对得上 → 当开场几枪，指针行必须打开对应模块看细节，禁止只靠短表半句生搬；③ 打完这几枪立刻回本站清单（`dig-scope` §4：先说清这摊、JS 抽钥匙、回包进队列）。肥面 JS/清单/回包出现**会执行、渲染模板、或调带命令的 RPC/工具**的形态 → 开**对应那一篇**当开场（不是通读 RCE 库、不是去打越狱），打完回清单；没抽到不发明参，RCE 按 `dig-scope` §4.2.1 没入口才 N/A，其它类型照挖。禁止把词表示例当成白名单。没号打有差分面的四件套，有号先对象图/换 id（§4.2.3），四件套打在这些业务参上；④ 磁盘有 `*src经验.md` 才和短表并行打开，没有不算缺。专篇是口径/死路簇，不是短表行，也不是本站清单。文件不长 → 整篇开。超长篇可先开点名那一节，不够、要对照、要编码/证伪 → 继续开同一篇里需要的段。现场对不上、要换打法 → 同一篇相关段都可开。只禁止每站把knowledge-base几十个文件通读一遍。表是空的、对不上、没写过这类 → 直接挖，不许停下来等表。原生会的手法不必先开库，现场需要细节时随时开。打开模块 ≠ 只测表上那一枪；四件套、越权/逻辑、本站清单、表上没有的面照样挖。 |
| 一行长什么样 | 认什么：框架或参数/业务形态，禁止写成某厂某产品某条 path 的或清单。打哪：path 或参数，是试法不是唯一入口；标「不登录」或「要会话」；两句封顶，多了进模块，短表写「见 xxx.md」。出什么算成：差分和拿到啥，必须能回答比基线多了谁的什么，禁止只写「接口 200」，禁止用更弱的成功条件把原门槛写矮。假点：只写「这种形态根本不是洞」。 |
| 假点 | 假点只记形态不是洞。禁止写进假点：「这站没注进去」「这站 401」「这次超时」。这次没打穿 = 这站现场不行，下一站同类手法照样打。套表打当前站没中 → 只说明这站不行。禁止因此把整行标失效、整行删掉、或下次当这手法不存在。只有确认「形态从来不是洞 / 整个手法前提没了」才改假点或删行。拿不准就不改表，继续挖。 |
| 短表肥了 | 按这个顺序，禁止一上来删。① 并：同一「认什么」多行合成一行。并完认什么仍是形态，不是「A 产品或 B 产品或 C path」。② 分流：某一簇不是一行能说清 → 细节并进已有对应模块，短表改成 1 行指针；没有对应模块再新建一个按手法命名的模块。禁止按日期/按任务拆 `shortlist-2026-08.md`。③ 只删这些：确认形态不是洞的废假点；确认整个手法前提没了；从没含金量误写进去的行（含单站备忘误写进表的）。④ 禁止删：仍可能出高危的手法行。冷门 ≠ 作废。单站没中 ≠ 手法死亡。禁止因为「以后只收高危」去翻旧表砍行。禁止把某次三问不过的字段名钉成永久黑名单（不进管的是这次写不进表，不是这个词永远不许当认法）。大约 80 行只是提醒该做 1～2 步，不是配额、不是到了就删。拿不准留不留 → 留，继续挖。 |
| 模块肥了 | 某一篇已经长到翻半天才找到手法 → 按手法/类型拆成两篇，短表指针改到新篇。禁止按月拆库、把旧长文搬进短表再删旧库、短表和模块全文互相复制（细节只在一处）。体积可以涨在文件夹多几篇对口的；每次读的仍是短表 + 需要的那一篇。 |
| 何时动文件 | 单窗自己挖到的高危：先过门槛，过了再三问 → 同一轮写/补短表，不等「放」。门槛没过或三问不过 → 不写、不问。子线程自己挖到的高危：只写本站 DONE 拟进/拟补/不进，禁止直接改短表；主控收回后先过门槛再三问，再写/补。用户丢来的报告 / payload：自己先看；有可对正文且过门槛+三问（或已过门槛只补模块差分）就补，不等「放」；不值得回一句不补。中危只写报告，不进表、不拟进、不补模块。真正确认形态不是洞 → 假点列。换站 / 换种 / 收工：不另写复盘。开新任务 / 拉子线程：起手写 `{名}_dig/线程必读.md`；spawn 交付必须含迭代。读磁盘本文件。 |
| 开场怎么用 | 开场几枪只打当前站。指针行必须打开对应模块。禁止认到就开新种子、FOFA 全网同皮。新根域只回灌，本种子挖完再搜。不是不许再挖这类站。本种子里、当前站上的同类面照样打。短表不是清单，不是上限，不是只准打表上的。打完开场立刻回 `dig-scope` §4，不要停在短表那一枪。执行类同样只打当前站；禁止认到助手/IDE/模板就 FOFA 全网同皮。有口按高价值苗头跟到执行或证伪；没差分立刻停，回清单打换 id / 改密 / 其余四件套。瘦壳、同闸不为执行多留 15 分钟。 |

## 二、不干什么

| 条 | 规则 |
|----|------|
| 不进短表 | 没出洞的流水；FOFA 条数；某站今天挖了啥；纯登录墙过程；同皮再确认；只用一次的 path；未交报告的目标 host；完整 token / 密钥实值。中危打穿了也不进。虚标（打开 format「漏洞等级」对正文，一条都没中）当没高危，不进；不以标题写高危为准。无新认的通用枪（换 id、空密、omit、列表自增、每个 path 丢 `'`）不进。进短表必须先过门槛，再过三问。不进短表 ≠ 矩阵少测一类。登录 / 重置 / 改绑 / 换票仍按 `dig-scope` §4.2.2 测。 |
| 禁止 | 用总结冒充挖洞进度；写表超过半分钟还在磨字。短表写成日记、周报、某 host 档案。没含金量进表；高危就进表；库里没有就丢；库里已有还另开一行；有新差分却不补原行；补行时把认什么改成产品/path 点名；把算成写成过签/缺参/接口 200；太窄（同形态认不到）还硬补；当教材去同构写废报告（测可以）。生搬短表；表没有就不挖；把表当本站唯一清单。单站没中就删手法 / 把「没打穿」写成假点。为防臃肿删旧库、删仍能出高危的行、按日期拆一堆短表、每站通读整库。借「省 token / 只读节」少开该开的模块、少测一类。自己写下的高危报告还等用户说「放」才进表。用户丢来的已经看懂、值得补，还空等「放」才动文件。拿表打断一种子闭环。借「迭代」少挖、少搜、少类型。开新任务不写线程必读；spawn 交付停在「落报告」；子线程直接改短表；主控不收拟进行。把迭代理解成挡换站 / 等并完短表才走 `dig-scope` §4.3。为了短收拾已有knowledge-base正文。把「没抽到执行类钥匙」读成本站永不测执行；把执行类例子当成白名单、清单外的执行面不挖；把 RCE 抬到整场换 id/改密前面当主业；认到执行类形态就开新种子 FOFA；把开模块理解成只测表上那一枪或改去打越狱；首页没扫到词就给 RCE 整段 N/A（清单/抓包/回包还没看）。 |
| 写不写 | 只认 `vuln-report-format.md`。本表不管 CORS / 发码 / 上传交不交报告，只说中危不进短表。短表和模块不定级、不另建建议等级表。细节一长写进对应旧模块，短表只留指针。 |
