# SRC 价值导向挖洞规则（强制经验）

> 来源：列表注入实战复盘。  
> 职责：保证测全常规漏洞类型、接口参数不漏，只推进真有危害的点。落不落、怎么写只认 `vuln-report-format.md`。  
> 进站节奏（说清这摊、JS 抽钥匙、有差分面、有会话对象图、中危升链）认 `dig-scope-workflow` §4；本文件管「挖什么、每类最低探针、力气怎么分（§1.1）」。

---

## 1. 挖什么：真价值优先

有价值 = 能打到高危/严重那档：跨租户/跨用户读或写、未登录出业务敏感、低权到平台管理员、注入出他主体、完整链（跨用户写、进号、命令跑起来）。怎么分力气、进站先砸哪，只认下面 §1.1。矩阵有入口仍勾或 N/A，不删类型。

**「管理员」语义（易误读，务必记准）：**
- 用户说注意「管理员」= 盯 **官方/平台级管理员权限** 是否可到，以及提权链
- **不是**「当前是租户 ADMIN 所以能看的都不算洞」
- 租户 ADMIN 是**跳板视角**：用本租户基线（如会话 total=2）对比注入/越权后是否变成海量/他租户

### 1.1 力气怎么分（先打更容易高危/严重的）

不删类型、不加第五件套、**XSS 与注入/SSRF/RCE 同等催**。进站顺序认 `dig-scope` §4；本表只管力气先砸哪。

| 先打 | 说明 |
|------|------|
| 未登录出他人/他主体 | 不登录出名单/详情/附件。**未授权通了再换 id（不限字段名）**（`dig-scope` §4.2.3）。文件通道开了转业务，别停在能传能下 |
| 认证接管 | 发会话 / 重置 / 改绑 / 换票；进号或改密才算（`dig-scope` §4.2.2） |
| 换 id（不限字段名） | 没号：未授权通了再换。有号：带着会话换（`dig-scope` §4.2.3）。他主体出现算打穿 |
| 有号写/逻辑 | 加 `role`、改金额/状态、跳审核、券/库存并发；盯租户身份能不能到**平台/官方**管理员 |
| 四件套全硬 | 有条数/回显打注入；会拉网址打 SSRF；有回显/能存打 XSS；有命令/模板跟 RCE。注入要出他主体或稳定差分 |
| JS 钥匙 | 盐、硬编码钥、演示号 |

**没号：** 未授权通了再换 id（不限字段名）→ 认证口 → JS 钥匙 → 有差分面的四件套（含 XSS）。  
**有号：** 带着会话换 id（不限字段名）→ 加字段/跳步/钱 → 四件套打在这些已经出数的业务参上（含 XSS）。

**有入口仍测，不当主业：** 只害自己的 CSRF（跨用户写成功仍跟）、能传能下没链、登录框弱口令。  
**清单里已经有的** GraphQL / 上传 / XML / WebSocket / XXE / 反序列化：本站打完或写 N/A，只是不插到换 id、接管前面。不是每站去找这些口；扒出来了不许装没看见。

## 2. 挖到这些别停在半截（测法）

落不落、标几级只认 `vuln-report-format.md`。这里只说怎么继续挖：

- 文件通道开了 → 立刻转业务 API、可执行/路径/SSRF 链  
- 发码接口通了 → 跟认证链：回包有没有码、码绑不绑号、重置换不换用户（`dig-scope` §4.2.2）  
- 滑块过了 / 能试密 → 表单壳停，打空密、跳步、重置、改绑  
- DSN/配置只有 host、没账密 → 继续找完整凭据；有账密/AKSK 当钥匙打：假值对照证明生产认，认钥枪须带出身份或列表，再打不影响线上的只读例（第一枪已带出则换另一类只读）。人账号出会话后同样打只读例，定级认 format。证伪当没钥。抄到就停手交报告 = 禁止。手机号加解密钥不当钥匙（落不落认 format）  
- CORS **不挖**（见 `cors-vuln-report-priority.md`）  
- 本职可读、公开静态、接口 200 有 JSON → 转跨用户/注入/提权  
- 回包里冒出 id / 下载地址 / token / 内部 host → 进本站队列再打（`dig-scope` §4.1.3）  
- **中危落了先升链再换站**：同一对象还没走到写 / 跨用户 / 接管 / 可执行，先跟（`dig-scope` §4.3）  

## 2.2 挖洞偏好禁令（永久）

- **禁止**挖 CORS  
- **禁止**把会话精力钉在未授权读/同构列表上，连续多日不碰 **注入 / SSRF / XSS / RCE**（细则见 `dig-scope-workflow` §4.2.1）。
- **必须**按 §3 类型矩阵推进：未授权、越权/IDOR（有会话与四件套同硬，见 `dig-scope` §4.2.3）、注入、SSRF、RCE 链、凭证泄露、弱口令（中间件裸默认口；**登录表单弱口令不当必做**，见 `dig-scope` §4.1.1；**JS/页里演示号当钥匙**）、敏感路径、XSS、上传、穿越、CSRF、提权、逻辑、**认证/任意登录/接管**（见 `dig-scope` §4.2.2）——**各种都要挖**（与 `dig-scope-workflow` §4.2 并集；**不含 CORS**）。
- 未授权读出一批后 → **立刻**对同批接口跑完 §3 注入参数表 + SSRF URL 参 + XSS 回显/存储 + RCE Sink（见 dig-scope §4.2.1，打在有差分面上）；禁止未授权写完就换站且四件套零 payload。
- 有会话后禁止只喷 `'`：对象图 / 换 id / 加字段 / 跳步 按 `dig-scope` §4.2.3。

## 3. 测全：类型矩阵（每轮目标至少过一遍）

对当前目标接口清单，按类型勾选，**不能只测信息泄露**。  
进站顺序认 `dig-scope-workflow` §4（先说清这摊，再抽钥匙、建清单、再测；本轮完成换站）。

| 类型 | 探针要求（有入口就打完；无入口 N/A+原因） |
|------|----------|
| 未授权 | 关键读/写 `credentials:omit`。通了再换 id（见下行） |
| 越权/IDOR | **有入口打完。** 没号：未授权通了再换 id。有号：基线 → 邻号 / 回包里抄的 id / `0`/`-1`/空 → 附件导出，见 `dig-scope` §4.2.3。不为第二号停工。 |
| 注入 | 能看出条数变、内容变、或会去拉一个网址的口：上面 **每个** 查询/过滤/排序/关键字参数都测（基线 → 探针 → 差分，详见 §4）。只回「请登录」、没有业务字段 → 整段 N/A，不要挨个丢 `'`。空列表 / 报错 / 超时不是请登录，对照见 `dig-scope` §4.1.2；没差分就停。**按栈选探针**：JSON/Mongo 打操作符；搜索框打 ES 或列表 OR+total；Java 打 HQL/SpEL；有模板打 SSTI；SQL 面仍走 `'`/布尔/延时/WAF 编码。被拦了换位置（query/json/header/path）。用户名/密码框不是业务参；登录接口上的 `tenant` / `corpId` / `moduleId` 有就打（`dig-scope` §4.1.1）。 |
| SSRF | 全部 URL/回调/webhook/file/fetch/import/preview/proxy 参：内网/元数据/外带 |
| RCE / 代码执行链 | 命令/表达式/模板/反序列化/危险上传等 Sink 跟到执行或证伪 |
| 凭证/密钥泄露 | 抄到 token/AKSK/私钥/连接串后：假值对照，认钥枪须带出身份或列表，再打不影响线上的只读例。人登录后台出会话定级认 format。占位/过期/真假同一句、调不到验钥口、手机号加解密钥 → N/A（不写，认 format）。 |
| 弱口令 / 默认口 | 中间件/组件裸默认口可一眼；打到真进会话。登录表单弱口令不当必做（`dig-scope` §4.1.1）。**JS/页里写死的演示号、测试租户当钥匙用。** |
| 敏感路径 | Swagger/Actuator/debug/heapdump/env 等；有没有密钥接着挖 |
| XSS | 反射（参数回显打标签/事件）+ 存储（可写点再读回）；结合是否无登录可读 |
| 上传 | 类型绕过、路径、可执行/SSRF 链；别停在能传能下 |
| 穿越 | fileKey/path/filename |
| CSRF/鉴权参数 | 无 ctoken / 坏 ctoken + Cookie 属性；写操作是否成功 |
| 提权 / 逻辑 | **有入口打完，密度对齐注入。** 写接口加 `role` / `isAdmin` / `amount` / `status` / `vip`（只改能改回去的）；多步流程跳步；钱/券/库存改小、改负、改小数；领取/审核看见就并发一枪。没有这类口 → N/A。有会话时见 `dig-scope` §4.2.3。 |
| 认证 / 任意登录 / 接管 | 清单有发会话 / 重置 / 改绑 / 换票 / 2FA → 按 `dig-scope` §4.2.2 勾完。用户名/密码框不当四件套 |
| CORS | **N/A · 不挖** |
| 其它现场面 | 矩阵未点名的现场面照样测；认证口走上一行 |

## 4. 接口与参数：禁止漏字段

1. 打开真实页面 → 抓**完整**请求（query + body）
2. 列出全部 filter/id 字段，**短枚举字段也要测**（如 `vote`、`answerType`、`status`）
3. 有差分面的口上，每个过滤参最低矩阵（只回「请登录」的口不在此列；用户名/密码框不是业务参，见 §3、`dig-scope` §4.1.1）：
   - 正常值 / 空 / 非法值
   - 按栈选探针：SQL 面 `'` / 布尔；JSON 面操作符；搜索框 ES/OR+total；Java HQL/SpEL；有模板 SSTI
   - 延时（按库型）
   - WAF 编码：`%0a` `%0d` 双写 注释 大小写 混用；**还要换位置**（query / json / header / path）
4. **差分是硬证据**：本租户基线 total/条数 vs payload 后 total/他主体字段

**教训实例（列表筛选项）：**
- `vote`：用户提示存在注入；当前多 405，可能已修，仍要回归
- `keyword=1%0aor%0a1`：WAF 可绕，total 从 2 → 数千万级，跨租户元数据 → **真 SRC 点**
- 漏测原因：只验「有没有数据」，没做「全参数注入矩阵」

## 5. 执行节奏

1. **资产齐套**：域名、登录态、菜单路由、JS 抽 API（含盐/密文 id/hidden 路由/演示号）、真实请求参数表；回包里的 id/url 补进清单  
2. **价值排序**：按 §1.1 力气先打未登录他主体 / 认证接管 / 换 id / 四件套（含 XSS）；信息泄露后置且降级表述  
3. **类型扫全 + 参数扫全**（有差分面优先）；新接口入队即测；有会话先对象图再喷参；CSRF/能传能下/登录框弱口令不当主业  
4. **只留可复核证据**（请求、差分表、关键字段）；不堆无效「收获」  
5. 打成了按 `vuln-report-format` 落盘；中危同一对象先升链；dig 不替代正文

## 7. 一句话

**测全类型与全参数；力气按 §1.1 先打更容易高危/严重的（未登录他主体 / 接管 / 换 id / 四件套含 XSS）；四件套打在有差分面上、按栈选探针；有会话则越权/逻辑与四件套同硬；认证口按 `dig-scope` §4.2.2 勾；CORS 不挖；用基线差分证明跨权/注入。中危先升链。落不落只认 `vuln-report-format`。**
