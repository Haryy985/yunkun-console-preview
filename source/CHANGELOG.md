## v1.0.2-offline：更新提醒与离线数据迁移

- 管理员顶部栏可检查可信 GitHub Release 的新离线版本、查看下载 SHA-256 和更新手册；网络不可用时不误报为最新，开发版不参与比较。
- 新增 `upgrade-offline.ps1`：要求停止旧服务，拒绝覆盖目标数据，先备份并核对旧安装，再迁移 `.yunkun-local/`、`bin/jwt.key` 与 Skills。旧安装和备份始终保留；不会自动下载安装或执行数据库回滚。
- 旧版本不含更新检查代码，需要先手动升级一次。新包已在本机隔离数据库上验证首次启动、健康接口及登录页；另一台干净 Windows 电脑上的登录和真实模型任务尚未验收。

## v1.0.1-offline：2026-10-16 Agent 稳定性

- Windows x64 完全离线包重新编译，内嵌当前前端并附带 PostgreSQL 18.4 运行时；更新流程见 [离线更新手册](docs/OFFLINE_UPDATE.md)。

- 对照原版执行路径复核输出预算：未设置 `MaxTokens` 时恢复 SDK 适配器原有默认行为（OpenAI 格式不发送上限，Anthropic 格式仍默认 8192）；仅接近本地容量时才额外限制输出。
- 未知窗口边界探测最低输出由 256 提升为 1024 Token，降低 Planner/Worker 因输出过短无法形成工具调用的风险；仍需真实模型任务验收。
- 修复旁路问答检查点把 `conv-*` 会话与任务归属同时写入数据库的问题，避免 `side_question_sessions_check` 约束错误和持续重试。
- 修复模型请求接近本地上下文上限时过早拒绝的问题；在仍有可用空间时自动缩小 `MaxTokens`，让 Planner/Worker 有机会执行。
- 将未知 64K 窗口的预算安全预留从固定 5% 调整为按窗口缩放，避免可执行的 Planner 请求被本地保护阈值提前拦截。
- 对未知模型窗口增加最多 16K 的有限软探测，并将边界请求限制为 1024 Token 探测，避免保守估算造成 Planner 假失败；明显超出范围仍保持本地保护。
- 保留上下文确实超过安全上限时的保护，避免把超长请求直接发送给模型网关。
- 增加父会话归属互斥测试和接近上限的预算回归测试。
- 本次修复不修改任务数据、模型凭据、知识库、代理池或历史会话。

## 2026-10-14 品牌迁移

- 产品名称统一为“云鲲自动化渗透控制台”，侧栏为“云鲲控制台”；登录后默认进入仪表盘。
- Go 模块与入口使用 `yunkun/console`、`./cmd/yunkun`，构建产物使用 `yunkun` / `yunkun.exe`。
- 当前配置只读取 `YUNKUN_*` 环境变量；数据库未配置时的提示仅列出 `YUNKUN_PG_DSN` 与 `config.json`。
- 管理员身份使用 `yunkun`，浏览器令牌与偏好使用新键，Worker 会话标记和抽取文档 MIME 使用新格式。
- 代理池与 FOFA/Quake 凭据使用新的加密关联标识；历史数据须先按 [迁移手册](migration/README.md) 检查、备份和转换。
- 原自动更新流程停用；使用当前 Release 离线包或源码自行构建，不要使用历史安装、更新命令。本仓库不提供公共镜像或在线 Demo。
- 公开源码排除业务配置、密钥、数据库、日志和生成产物；Release 离线包单独包含已编译程序与 PostgreSQL 运行时，不包含个人运行数据。

此批变更不自动切换已有安装。实际验证结果与剩余边界见本版 [Agent 修复记录](docs/agent-reliability-2026-10-16.md) 和 [离线更新手册](docs/OFFLINE_UPDATE.md)。

## 继承的功能基线

以下能力来自既有项目及此前维护工作，不对应云鲲仓库中的发布标签：

- Agent 对话、任务规划与 Worker、旁路提问、模型配置和用量记录。
- 任务事件、SSE 执行流水、审批、归档、模板及批量操作。
- RAG 文档解析、检索与知识修订审批。
- 流量录制、Finding、证据快照、HTTP 请求包与报告。
- 代理来源、FOFA/Quake 发现、节点管理、任务租约与出口审计。
- RBAC、认证故障恢复、通知与持久化存储。

当前构建、运行和更新步骤见 [README](README.md)。后续版本与发布记录统一在 [交付仓库](https://github.com/Haryy985/yunkun-console-preview) 维护。
