# 云鲲 v1.0.3：Skills 融合、证据质量与稳定性更新

本版面向 Windows x64 离线交付。在保留现有 Agent 规划、模型选择和执行循环的基础上，
合并此前开发分支中的修复，补齐工作流资料、质量审核、HTTP 证据报告和代理池改进。

## 下载与安装

从本仓库 [v1.0.3 Release](https://github.com/Haryy985/yunkun-console-preview/releases/tag/v1.0.3-offline)
下载 `yunkun-v1.0.3-offline-windows-x64.zip` 和 `SHA256SUMS.txt`。
GitHub 自动生成的 Source code ZIP 是源码快照，不是离线安装包。

- 修订后压缩包：约 96.2 MB，内含官方 VC++ x64 离线运行库安装器。
- 修订版 SHA-256 以发布页最新 `SHA256SUMS.txt` 为准。
- 解压后双击 `setup-and-start-offline.bat`，等待就绪后访问 `http://127.0.0.1:5173/`。
- 需要公网访问时，在云安全组和 Windows 防火墙放行 TCP 5173，再运行
  `powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\setup-and-start-offline.ps1 -Public -NoBrowser`。
- 管理员账号为 `yunkun`，首次自行设置密码，没有统一默认密码。

包内含编译后的控制台、当前内嵌页面、PostgreSQL 18.4 和工作流资料。
安装与本机启动不需 Go、Node、Docker 或下载依赖；云端模型、第三方查询平台及
可选测试工具仍需使用者自行准备。包内不含维护者的数据库、密钥、任务、日志或平台账号。

## 相对 1.0.2 的新增

| 功能 | 本版内容 | 使用方式 |
| --- | --- | --- |
| Skills 工作流 | 云鲲验证与交付入口，专项规则、参考资料和模板；合计 349 个 Skills 文件 | 在 Skills 中按需阅读相关章节，不一次加载全部资料 |
| Go 原生工具 | `analyze_web_surface` 静态页面分析；`asset_intel_search` 查询 FOFA、Quake、Hunter、ZoomEye；`threatbook_lookup` 查询信誉 | 静态工具处理已取得的文本；外部情报需配置自己的凭据并由管理员绑定 |
| 目标画像 | 保存带范围、来源和置信度的观察；Agent 按需读取有限条目 | 在同任务范围内复用观察，不把推断当事实，也不自动扩大范围 |
| 漏洞质量审核 | PASS、NEEDS_MORE、DOWNGRADE、DUPLICATE_RISK、BLOCKED 状态，人工复现与证据核对 | 证据改变后重新审核；正式导出需满足质量及版本要求 |
| 独立报告入口 | 实际 HTTP 请求包、关键响应和证据附件 | 缺失或截断明确标记，不根据 URL 补造请求，不用 curl 代替复现包 |
| 审核式知识积累 | 已验证 Finding 可带可复用经验生成 RAG 待审核提案 | 校验知识库授权及敏感信息；人工批准后才进入检索 |

## 修复与优化

| 模块 | 变化 |
| --- | --- |
| Agent 上下文 | 移除二开引入的未知模型固定 64K 本地请求拦截，保留原有可配置压缩。供应商真实容量仍需正确配置，不能据此保证长任务永不超窗。 |
| 模型工具回合 | 保留 SDK 捕获的 reasoning 数据。对缺少历史推理且没有显式 thinking 配置的特定拒绝，仅在输出未提交时尝试关闭 thinking；不编造推理内容，不全局关闭思考。 |
| 错误处理 | 区分上下文过长、额度耗尽、暂态传输及明确的订阅不可用，不把普通鉴权失败当额度耗尽，不无限重试。 |
| FOFA / Quake 发现 | 每次 100–1000 条，持久保存下一页位置；结果和游标事务提交。失败重试当前页，业务错误不误判为结果取尽；条件变化后重置游标。重复结果仍去重，不保证每次都产生新 IP。 |
| 代理验证 | 全服务最多同时验证 10 个，每个实际验证限时 3 秒；排队时间不计入连接期限，取消与配置变化受检查。 |
| 跨页全选 | 选择当前筛选下全部可操作候选，分批提交；已入池节点在节点页管理。 |
| Finding 质量 | 要求验证过程和本任务真实成功工具步骤或核实流量引用，证据不足保留为线索，避免只凭状态码、版本或扫描器告警确认漏洞。 |
| 报告导出 | Markdown 交付视图清理旧 curl 复现命令及其续行；动态代码围栏避免证据内容破坏 Markdown。保密 HTTP 原文经权限检查和审计输出。 |
| 初始化认证 | 读取失败默认拒绝，并发首次设置不能覆盖已有密码；密码版本使旧会话失效，损坏签名密钥不静默重建。 |
| 文件与请求边界 | 加固工作空间路径、上传与 Skills ZIP 安全替换；数据库标识符正确引用；跨域仅接受明确配置的可信 Origin。 |
| 云鲲界面 | 保留分组导航、模型及设置页排版，同时合并画像、质量审核、报告与版本入口。 |
| 离线迁移 | 增补代理凭据加密密钥迁移，完整备份后校验哈希；保留自定义 Skills，同名新版默认资料另留供对比。 |

## 更新提醒与升级

1.0.2 已具备基础版本检查，本版补齐它与当前导航、设置页的连接。
管理员可查看新版、发布说明及下载入口。需要能访问 GitHub；断网不会收到在线提醒。
目前不自动替换运行中的程序，早于检查功能的旧安装需要先手动升级一次。

不要覆盖正在使用的旧目录。暂停任务并停止旧服务，将新包解压到全新目录，
按[离线更新手册](OFFLINE_UPDATE.md)运行 `upgrade-offline.ps1`。
脚本先备份旧安装，再迁移私有数据、JWT 密钥、代理加密密钥和用户 Skills，并校验哈希。
旧目录与备份均保留。外部数据库或自定义绝对路径须单独确认。

## 当前边界

没有把全部 Python 脚本改写成 Go。主动爬取须先接通受管出口及抓包，再作为新工具开放；
专项资料不等于全部脚本已成为运行能力。原生 Agent 仍继承启动账号权限，
局部证据关联也不等于跨任务完整因果图。

本版未用真实模型、付费情报平台和真实授权目标跑完整任务。
自动测试不等于无漏洞或公网部署验收；独立报告交付角色和运行中自动升级尚未提供。
既有许可证、来源和仓库使用条款保持有效。
